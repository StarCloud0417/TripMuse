# TripMuse Product Overview

TripMuse is an AI-powered intelligent travel planning application built with Flutter and MapBox Maps SDK. The app transforms travel ideas into personalized itineraries using artificial intelligence.

## Core Features
- **AI Trip Generation**: Generate personalized itineraries using natural language descriptions via Gemini API
- **Interactive Maps**: Beautiful map visualization with route planning using MapBox SDK
- **Cross-Platform**: iOS and Android support with Flutter
- **Offline Support**: Access trips without internet connection using Hive local storage
- **Google Places Integration**: Enhanced place data with photos, ratings, and details
- **API Testing Interface**: Built-in testing tools for API endpoints and health monitoring

## Target Users
Travel enthusiasts who want intelligent, personalized trip planning with beautiful map visualization and offline capabilities.

## Current Status (v0.1.6)
The app is in active development with core architecture established, AI trip generation working, Google Places API integrated, and comprehensive testing infrastructure in place.
