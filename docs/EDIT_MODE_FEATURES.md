# TripMuse 編輯模式功能說明

## 新增功能概述

本次更新為 TripMuse 應用程式添加了完整的行程編輯模式功能，讓用戶可以輕鬆管理和調整行程中的活動。

## 功能詳細說明

### 1. 編輯模式切換
- **進入編輯模式**：點擊行程詳情頁面右上角的選單按鈕（三個點），選擇「編輯行程」
- **退出編輯模式**：點擊編輯工具欄中的「完成」或「取消」按鈕

### 2. 編輯工具欄
當進入編輯模式時，頁面頂部會顯示藍色的編輯工具欄，包含：
- 編輯模式指示器（藍色標籤）
- 操作提示文字：「拖拉活動調整順序，長按編輯內容」
- 完成按鈕（綠色勾號）
- 取消按鈕（紅色 X）

### 3. 活動卡片編輯功能

#### 非編輯模式下：
- 點擊活動卡片：查看活動詳情
- 長按活動卡片：進入編輯模式

#### 編輯模式下：
- **視覺變化**：
  - 活動卡片邊框變粗，顏色更鮮明
  - 顯示拖拉手柄圖標
  - 右側顯示編輯控制按鈕

- **編輯控制按鈕**（右側紅圈區域）：
  - **刪除按鈕**（紅色圓形，垃圾桶圖標）：刪除該活動
  - **向上箭頭**（藍色圓形）：將活動向上移動一個位置
  - **向下箭頭**（藍色圓形）：將活動向下移動一個位置

- **智能顯示**：
  - 第一個活動不顯示向上箭頭
  - 最後一個活動不顯示向下箭頭

### 4. 拖拉功能
- 在編輯模式下，可以拖拉活動卡片來調整順序
- 拖拉時會顯示半透明的拖拉反饋
- 拖拉過程中原位置顯示佔位符

### 5. 時間編輯功能
- 在編輯模式下，點擊時間區域可以編輯活動時間
- 支援時間選擇器
- 自動驗證時間格式和邏輯

## 如何在 APP 中測試新功能

### 步驟 1：進入行程詳情頁面
1. 打開 TripMuse 應用程式
2. 選擇任一行程
3. 進入行程詳情頁面（時間軸視圖）

### 步驟 2：進入編輯模式
1. 點擊右上角的選單按鈕（三個點圖標）
2. 選擇「編輯行程」選項
3. 觀察頁面頂部出現藍色編輯工具欄

### 步驟 3：測試編輯功能
1. **測試刪除功能**：
   - 點擊任一活動右側的紅色刪除按鈕
   - 確認刪除對話框
   - 觀察活動被移除

2. **測試排序功能**：
   - 點擊活動右側的藍色向上/向下箭頭
   - 觀察活動位置變化
   - 注意第一個活動沒有向上箭頭，最後一個活動沒有向下箭頭

3. **測試拖拉功能**：
   - 長按並拖拉活動卡片
   - 觀察拖拉反饋和佔位符
   - 釋放後觀察活動位置變化

4. **測試時間編輯**：
   - 點擊活動的時間區域
   - 使用時間選擇器修改時間
   - 確認或取消修改

### 步驟 4：退出編輯模式
1. 點擊編輯工具欄中的「完成」按鈕保存變更
2. 或點擊「取消」按鈕放棄變更
3. 觀察編輯工具欄消失，活動卡片恢復正常樣式

## 技術實現

### 主要組件
- `TripEditModeProvider`：管理編輯模式狀態
- `TripEditToolbar`：編輯工具欄組件
- `DraggableActivityCard`：可拖拉的活動卡片
- `ActivityEditProvider`：活動編輯操作管理

### 新增方法
- `moveActivityUp()`：向上移動活動
- `moveActivityDown()`：向下移動活動
- `deleteActivity()`：刪除活動
- `updateActivityTime()`：更新活動時間

## 用戶體驗改進

1. **視覺反饋**：編輯模式下活動卡片有明顯的視覺變化
2. **操作提示**：編輯工具欄提供清晰的操作指引
3. **確認對話框**：刪除操作有確認對話框防止誤操作
4. **觸覺反饋**：拖拉和按鈕操作提供觸覺反饋
5. **狀態提示**：操作完成後顯示 SnackBar 提示

## 注意事項

1. 編輯模式僅在時間軸視圖中可用
2. 所有編輯操作會自動保存到本地存儲
3. 編輯過程中的錯誤會通過 SnackBar 顯示給用戶
4. 拖拉功能和按鈕操作功能可以同時使用
