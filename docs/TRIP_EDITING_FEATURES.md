# TripMuse 行程編輯功能說明

## 新增功能概覽

本次更新為 TripMuse 應用程式新增了完整的行程編輯功能，包括自動儲存機制、活動刪除和地圖更新邏輯、跨日期活動移動功能，以及路線重新計算和最佳化。

## 主要功能

### 1. 自動儲存機制 (Auto Save Service)
- **檔案位置**: `lib/tripmuse/services/auto_save_service.dart`
- **功能描述**: 
  - 每 30 秒自動儲存編輯中的行程
  - 防抖機制：編輯後 3 秒內無新變更才執行儲存
  - 提供儲存狀態指示器
  - 支援立即儲存功能

### 2. 路線最佳化服務 (Route Optimization Service)
- **檔案位置**: `lib/tripmuse/services/route_optimization_service.dart`
- **功能描述**:
  - 計算活動間的距離和旅行時間
  - 支援多種交通方式（步行、騎車、開車、大眾運輸）
  - 自動最佳化活動順序以減少總旅行距離
  - 驗證時間安排的合理性
  - 自動調整活動時間以符合交通需求

### 3. 增強版活動編輯服務 (Enhanced Activity Edit Service)
- **檔案位置**: `lib/tripmuse/services/activity_edit_service.dart`
- **新增功能**:
  - 跨日期移動活動
  - 批量刪除活動
  - 整個行程的路線最佳化
  - 自動調整行程時間
  - 驗證整個行程的時間安排
  - 計算行程統計資訊

### 4. 增強版編輯工具欄 (Enhanced Trip Edit Toolbar)
- **檔案位置**: `lib/tripmuse/widgets/enhanced_trip_edit_toolbar.dart`
- **功能描述**:
  - 美觀的滑動動畫效果
  - 自動儲存狀態顯示
  - 交通方式選擇器
  - 快速操作按鈕（路線最佳化、時間調整）
  - 進階選項（智能排序、時間驗證、行程統計）

### 5. 跨日期活動移動對話框 (Move Activity Dialog)
- **檔案位置**: `lib/tripmuse/widgets/move_activity_dialog.dart`
- **功能描述**:
  - 直觀的日期選擇介面
  - 顯示每日活動數量
  - 防止移動到當前日期
  - 美觀的 Material Design 介面

### 6. 增強版可拖拽活動卡片 (Enhanced Draggable Activity Card)
- **檔案位置**: `lib/tripmuse/widgets/draggable_activity_card.dart`
- **新增功能**:
  - 跨日期移動按鈕
  - 改進的刪除確認對話框
  - 更好的視覺回饋

## 在應用程式中的使用方式

### 如何進入編輯模式
1. 開啟 TripMuse 應用程式
2. 選擇任一行程進入詳情頁面
3. 點擊右上角的選單按鈕（三個點）
4. 選擇「編輯行程」或點擊浮動編輯按鈕

### 編輯模式功能
進入編輯模式後，您可以：

1. **拖拽活動調整順序**
   - 長按活動卡片進行拖拽
   - 在同一天內重新排列活動順序

2. **編輯活動時間**
   - 點擊活動卡片上的時間區域
   - 使用時間選擇器調整開始和結束時間

3. **移動活動到其他日期**
   - 點擊活動卡片上的日曆圖示
   - 在彈出的對話框中選擇目標日期

4. **刪除活動**
   - 點擊活動卡片上的刪除按鈕
   - 確認刪除操作

5. **路線最佳化**
   - 在編輯工具欄中選擇交通方式
   - 點擊「最佳化」按鈕自動調整活動順序

6. **自動調整時間**
   - 點擊「調整時間」按鈕
   - 系統會根據交通時間自動調整活動時間

### 自動儲存功能
- 編輯過程中會自動儲存變更
- 工具欄顯示儲存狀態（儲存中、已儲存、儲存失敗）
- 可點擊「立即儲存」按鈕手動觸發儲存

### 進階功能
點擊工具欄的展開按鈕可存取：
- **智能排序**: 根據地理位置智能排列活動
- **時間驗證**: 檢查時間安排是否合理
- **行程統計**: 查看總距離、旅行時間等統計資訊

## 技術實作細節

### 狀態管理
- 使用 Riverpod 進行狀態管理
- 自動儲存狀態與編輯狀態分離
- 支援錯誤處理和載入狀態

### 資料持久化
- 整合現有的 Hive 本地儲存
- 支援離線編輯
- 自動同步到雲端（如果已設定）

### 效能最佳化
- 防抖機制減少不必要的儲存操作
- 批量操作支援
- 智能快取機制

### 測試覆蓋
- 單元測試覆蓋核心邏輯
- 整合測試驗證完整流程
- 測試檔案位置：`test/tripmuse/trip_editing_test.dart`
